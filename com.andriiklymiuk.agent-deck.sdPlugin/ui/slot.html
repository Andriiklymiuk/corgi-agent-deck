Every key is one Claude Code session. Press to bring its window and terminal tab forward; hold for pin. An empty key opens a new session; the +N key pages through the rest.
Set up once on this Mac: corgi agent install, then corgi agent track enable, and install the corgi VS Code extension for exact tabs.
The Talk key presses the dictation chord in the session in front of you. For a terminal session run /voice tap once in Claude Code and bind voice:pushToTalk to the chord above in ~/.claude/keybindings.json; the Claude Code panel takes its own shortcut (cmd+d). Stream Deck needs Accessibility to send either.
